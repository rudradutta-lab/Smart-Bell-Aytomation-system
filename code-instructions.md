# Code Instructions

1. Install Arduino IDE.
2. Install ESP32 board support.
3. Connect ESP32 using USB.
4. Select ESP32 Dev Module.
5. Select the correct COM port.
6. Open SmartBell_Automation.ino.
7. Upload the code.
8. Open Serial Monitor at 115200 baud.
9. Check the IP address.
10. Connect your phone to the same Wi-Fi.
11. Open the IP address in your browser.
12. Control the Smart Bell using the dashboard.
